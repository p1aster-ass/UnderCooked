## About The Project

**UnderCooked** is an open-source project designed to bring the heat to your kitchen. Whether you are coordinating complex tasks, managing resources, or just trying to serve the soup before the timer runs out, UnderCooked provides a flexible, fast, and heavily customizable environment.

## Features

* **Blazing Fast**: Optimized resource management keeping overhead to a minimum.
* **Highly Configurable**: Tweak settings, levels, and mechanics via simple JSON configs.
* **Cross-Platform**: Run it seamlessly on Windows, macOS, and Linux.
* **Custom Assets**: Easily swap out sprites, sounds, and UI elements.
